# PROD 2025. Приложение для занятий спортом

Были реализованы все основные фичи и дополнительные улучшения. Вся информация о упражнениях, тренировках и пользователе сохраняется после перезагрузки страницы.

## Профиль пользователя

При первом заходе на сайт пользователь указывает данные о себе: возраст, рост, вес, которые можно потом изменить. На основе этих данных подсчитываются цели упражнений.

## Список упражнений

Есть фильтры по названию, описанию, выбору тега или инвентаря, а также сложности упражнения - простое/среднее/сложное (разделено условно).

Нажав на кнопку плюса можно добавить упражнение, указав необходимые данные (дополнительно описание, несколько ссылок на картинки или ссылку на видео на ютубе, рутубе или прямую ссылку на видео файл).

При некорректных данных покажет, что неверно заполнено. При редактировании уже созданного упражнения можно изменять все те же поля.

## Список тренировок

Есть поиск по названию тренировки.

Также по плюсу можно добавить тренировку, указав ее название и составляющие упражнения с целью выполнения к каждому.

Если список упражнений еще пуст, можно составить рандомную тренировку по тегу, вписав его в соответствующее поле ввода.

При добавлении упражнения в тренировку цель автоматически заполняется по формуле, зависящей от параметров пользователя (формула очень неточная).

Также при указании слишком большой цели (высчитывается также по формуле из параметров пользователя) приложение выдаст предупреждение, но с возможностью все таки сохранить такие значения.

Можно сохранить редактируемую тренировку или запустить разово.

## Режим тренировки

При запуске тренировки с слишком большой целью также показывается предупреждение.

На упражнениях с единицей измерения времени предлагается запустить таймер. При нескольких подходах таймер запускается столько же раз, каждый после готовности пользователя.

Упражнение можно пропустить

Между упражнениями отдых 20 секунд, который можно уменьшать и увеличивать по 10 секунд.

По завершении тренировки показывается информация о завершенных и пропущенных упражнениях, а также уведомления о новых уровнях и ачивках.

## Геймификация для пользователя

За завершение тренировок, выполнение повторений и подходов, подсчет секунд упражнений, пользователь получает опыт, который увеличивает уровень и очки, за которые можно покупать предметы кастомизации для своего аватара.

Есть магазин, в который можно перейти из профиля.

Также в профиле указаны ачивки: полученные и нет.
